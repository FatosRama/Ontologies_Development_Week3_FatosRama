# Ontologies_Development_Week3_FatosRama

This workspace contains two main folders of the tasks completed for Week 3 of Ontology Development:

## FeRAM Ontology
This folder contains the FeRAM ontology diagram for week 3 work:
- `ferroelectric_memory_Week3.drawio` - the editable diagram source
- `ferroelectric_memory_Week3.drawio (2).png` - a rendered image of the diagram

## SMT2020 Ontology
This folder contains the ontology development files for the SMT2020 dataset:
- `createProcessStepIndividuals.py` - creates process step individuals and step-to-step links
- `dataPropertyBreakdown.py` - maps breakdown data into ontology properties
- `dataPropertyPM.py` - maps preventive maintenance data into ontology properties
- `dataPropertyProcessSteps.py` - adds data properties to process step individuals
- `dataPropertySetupGroup.py` - maps setup group data into ontology properties
- `dataPropertyToolGroup.py` - maps tool group data into ontology properties
- `ontology_development_week3_final.ttl` - the final ontology file
- `ontology_development_week3_final.ttl (1).svg` - a visual export of the ontology
